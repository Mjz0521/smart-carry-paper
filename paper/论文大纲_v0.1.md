## 一、选题定位

### 1.1 一句话贡献

> 给出一种低成本、可复现的「树莓派视觉 + STM32 运动控制」分层架构，
> 并用实测数据量化其在通信、视觉、运动三个层面的性能边界。

### 1.2 三个可写进摘要的贡献点

1. **分层架构**：Pi 负责视觉决策，STM32 负责实时运动，ASCII + 异或 CRC
   的轻量协议在 115200 8N1 下实现毫秒级往返。
2. **量化评估**：给出串口往返时延、长时通信可靠性、Pi5 视觉帧率/温度、
   电机定位重复性四组实测数据，填补同类工程论文"只讲方案不讲数据"的空缺。
3. **模式对比**：串口位置模式与脉冲模式在同一负载下的定位精度对比，
   给出控制方式选择依据。

### 1.3 不做什么（避免审稿人质疑）

- 不声称算法创新：HSV + 卡尔曼是成熟方法
- 不声称整机性能世界领先
- 不做深度学习对比（资源受限场景下不作为基线）

## 三、各章要点

### 1 引言

- 智能搬运在工程竞赛与仓储物流中的需求
- 现有方案：PC + 工控机（成本高）、纯 MCU（视觉弱）、ROS 方案（部署重）
- 边缘计算 + 异构架构的兴起
- 本文工作：架构设计 + 性能评估，全部代码与实验可复现

### 2 系统总体设计

- 分层：感知层（USB 摄像头）→ 决策层（Pi5）→ 执行层（STM32F103ZET6 + Emm42）
- 为什么这样分：Pi 有 Linux/OpenCV，STM32 有硬实时和丰富外设
- 通信：USART3 115200 8N1，ASCII 行 + 异或 CRC，`$F/$T/$S/$K/$P`
- 关键设计取舍：
  - 图像中心 ≈ 爪心（眼在手上），避免绝对坐标标定
  - 非阻塞运动层，主循环同时处理串口与急停
  - 同步触发（多电机同时起步）

### 3 关键实现

- 视觉：HSV 阈值 → 形态学 → 轮廓 → 圆度/面积过滤 → 卡尔曼滤波
- 坐标变换：`dx=(v0-v)·s`，`dy=(u0-u)·s`，单位 0.1 mm
- 串口链路：环形缓冲 + 行解析 + CRC + ACK
- 运动：Emm42 位置模式，16 细分 3200 脉冲/圈，四轮麦轮运动学分配
- 状态机：IDLE → LIFT_SCAN → APPROACH → SETTLE → WAIT_SCAN → ALIGN → GRAB → DONE
