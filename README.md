## 二、工作流

```
调试 → 记录参数 → 跑实验脚本 → CSV 落 data/
     → 生成图 → figures/
     → 写记录 → records/
     → 定期汇总进论文 → paper/
```

**三条纪律**：

1. 原始数据不改，统计和清洗另写脚本。
2. 每次实验记录电源、负载、环境光、代码版本。
3. 代码与数据要能对上——重要实验前给代码打 git tag。
